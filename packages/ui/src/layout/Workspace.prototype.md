# Throwaway workspace study

Question: can a quieter hierarchy and predictable actions make Chat, Calendar, Tasks, Wiki, and You feel consistent while retaining glass and bottom navigation?

`Workspace.prototype.tsx` exports two presentation alternatives and their external comparison bar through `@smoked-glass/ui/prototype`. Workspace keeps a collection beside detail; Focus uses one canvas with an on-demand collection. The Facet preview supplies the current application as the third variant, equivalent fictional records, and in-memory action handlers.

Run `npm run dev:ux` in [Facet's prototype branch](https://github.com/JimLundin/facet/tree/prototype/ux-hierarchy). Its [study notes](https://github.com/JimLundin/facet/blob/prototype/ux-hierarchy/docs/design/ux-prototype.md) capture the question, scenarios, before/after review, provisional verdict, and validation. All styles are scoped; the existing kit exports and default application remain unchanged.

This branch is the primary source for the experiment. Workspace is recommended for review, but no variant has been selected for production. Rewrite any chosen behavior in its proper production composition; do not promote this prototype module.
