Badge is a small capsule label for status or a count, set in the `rounded` family at 12px / 600.

**Consumer provides** the text (`children`), `tone` and optionally `icon`.

Tones: `neutral` (`fill-control`, `label`), `accent` (`accent-tint`, `accent-text`), `success` / `warning` / `danger` (`fill-control` with the matching `*-text`), `count` (`danger-fill`, white numerals).

- Do: pair `success` and `danger` with an icon or an unambiguous word — never colour alone.
- Do: place on `canvas`, `canvas-raised` or thick glass.
- Don't: use badges as buttons.
