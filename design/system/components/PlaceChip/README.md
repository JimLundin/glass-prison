PlaceChip is a location mentioned inside another module — an event's venue, a task's address, a place in a chat answer or wiki page. Tapping it opens the place on the full map.

**Consumer provides** `name`, and `onClick` or `href` (omit both for a passive mention).

Locations have no tab of their own: they live in the things that mention them and open as a map view over the current module.
